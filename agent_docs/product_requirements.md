# Product Requirements Matrix

## Must-Have Features (Phase 1-4)
*   **MV3 Service Worker:** Persistent message brokerage between popup and injection contexts.
*   **Dictionary Keyword Mappings:** Fallback parsing routines mapping `surname` data models to variants like `lastname`, `family_name`, and `last_name`.
*   **Supabase Fetch Protocol:** Zero-dependency `fetch` pattern passing security bearer authorizations directly via HTTP request headers.

## Nice-to-Have Features
*   Dynamic user field overrides inside the popup window before submission execution.
