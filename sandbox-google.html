Visa Application (Google-Forms-Style)

Mimics a real Google Form: each question lives in a div[role="listitem"] container with the prompt in a sibling div[role="heading"]. Inputs carry no id, name, or placeholder, forcing the auto-filler to resolve labels via aria-labelledby, aria-label, or the heading-walk fallback. One field uses contenteditable. A hidden CSRF token at the bottom verifies the EC-01 guardrail still holds.
